# Dalaux

> Systems that move business forward.

Dalaux is an independent digital studio for teams that want to make the complex feel obvious. This starter site presents the agency's three core offers: AI automation, high-converting web experiences, and growth systems.

## What's inside

- Vite + React + TypeScript
- Responsive editorial-style landing page
- Accessible navigation and semantic sections
- Lightweight CSS system with no UI framework dependency
- GitHub Actions build check on pushes and pull requests

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Project structure

- `src/App.tsx` — page content and section composition
- `src/styles.css` — responsive visual system
- `src/main.tsx` — application entry point
- `.github/workflows/ci.yml` — automated build check
